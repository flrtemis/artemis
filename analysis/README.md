# ARTEMIS unification design package

Start with **unified-system-report.html**. It is a self-contained report with a source-grounded design, searchable 146-row disposition ledger, metric audit, validation scope and preserved proposals/history. It is not a running product prototype. It requires no network/fonts/scripts/assets to read; GitHub evidence links require internet when opened.

- **unified-system-report.md** — main design in portable Markdown.
- **capability-ledger.md / capability-ledger.csv** — all decisions, status, preserved value, canonical owner/workflow, rationale and commit-pinned sources.
- **neural-metric-audit.md** — all 48 AI families and 41 BioMetrics fields, actual formulas, semantic repairs and correctness gates.
- **proposals-and-history.md** — nine unregistered operational proposals and recovered/deleted history treatment.
- **audit-validation.md / validation-results.json** — exact snapshots, bounded executed checks, defects, positive findings, limitations and privacy/rights cautions.
- **file-manifest.csv** — all 4,958 tracked files with size/hash/classification/source URL.
- **file-disposition-map.csv** — all files mapped to review treatment/disposition IDs; no line-by-line third-party audit claim.
- **source-evidence-index.csv** — commit-pinned source links used in the report and ledger.
- **architecture.svg** — proposed subsystem ownership/topology.
- **package-sha256.txt** — delivery-file integrity hashes (excludes itself and the ZIP).

**Preservation does not imply implementation.** Experimental/proposed/mocked work is explicitly labelled. “Retired” means removed from active runtime/UX after an accepted disposition, not deletion of development history or private user continuity.

Audit date: 2026-09-29. Seven snapshots: command-center 5226291, agent a09f1d2, local_ollama_arena_agent c95d307, gemma-avatar c4becc8, Sage 701f917, neural-sim b51dda7, universe 458915e. Full hashes are in the census and source links.

The package contains no personal diary/database contents, copied model weights or full repository clones. Source clones and bounded audit scripts were used for research; the exact public commits and embedded bundle preserve provenance. No model/GPU/full-browser/audio backend validation is claimed.
